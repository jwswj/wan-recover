# Security

Do not expose the HTTP listener publicly. Use a dedicated, source-restricted
forced-command gateway key, pin the gateway host key, and store Meross and HTTP
keys outside version control. Only control a modem-only outlet whose failure
cannot disconnect the service from the plug.

If you find a vulnerability, use the repository's private security reporting
facility when available. Do not put credentials or exploit details involving
someone else's network into a public issue. Unsupported firmware is expected
to inhibit new cycles rather than guess the state of an interface.
